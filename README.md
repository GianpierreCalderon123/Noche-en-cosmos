# Una noche en Cosmos ✦ Lima

Experiencia web 3D inspirada en una sangría hawaiana, tequeños y la Plaza San Martín de Lima.

## Ver el sitio

Activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**.

URL prevista: https://gianpierrecalderon123.github.io/Noche-en-cosmos/

## Fotografías

Para mostrar las dos fotografías originales, sube estos archivos a la carpeta `assets`:

- `assets/sangria.jpg`: foto de la sangría y tequeños.
- `assets/plaza.jpg`: foto nocturna de la Plaza San Martín.

La página usa estos nombres exactos. El resto del sitio funciona sin dependencias ni compilación.
